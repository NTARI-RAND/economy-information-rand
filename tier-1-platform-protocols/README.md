# Tier 1: Platform Protocols

*The goal of Tier 1 is to understand the exchange each platform exists for, and write a protocol that fits it.*

Every platform has its own protocol. Each stays inside the credit lines: IOUs created at trade (line 1), earned never bought (line 2), one sovereign unit per community (line 3), escrow first (line 10).
